## Design Checks

- Deep experience: L3 v1 composes room flow, combat objective, reward choice, Build application, and endpoint result without introducing a new economy.
- Light cognition: the only new player-facing control is Next after room completion; each room keeps one primary intent.
- Progressive exposure: fixed path is combat → reward → combat → rest → endpoint.
- Readable feedback: room intent, reward options, floor progress, next-room availability, and victory all have placeholder text/color UI.
- Reversible: room path, room types, reward offer count, and rest/endpoint auto-complete are JSON/config driven or isolated behind EventBus.

# L2.5 里程碑总览：Virtual Player 测试基础设施

> **核心目标：** 构建与游戏系统完全解耦的虚拟玩家输入系统，支持自动化测试和人类游玩模拟。作为 L3 开发的前置基础设施。

## 架构决策

- 五层架构：GamePerception（感知）、InputInjector（注入）、HumanTiming（时序）、PlayerBrain（决策）、VirtualPlayer（编排）
- 信息边界：只暴露玩家视觉可见信息，禁止访问内部状态
- 双模式：确定性模式（测试用，0 延迟）+ 人类模式（~200ms 反应延迟）
- 输入管线注入 InputEventAction + headless fallback 到 _buffer_direction()
- 可插拔大脑：ScriptedBrain、SurvivalBrain、FoodSeekerBrain、CompositeBrain
